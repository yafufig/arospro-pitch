# АросПро

Основной клиентский лендинг на GitHub Pages: арос.tech.
Репозиторий: https://github.com/yafufig/arospro-pitch

Первый экран показывает складской сценарий: коробку на полке и считывание маркировки. Конкретный внешний вид будущих очков не изображён. SVG встроен в HTML; движение линии считывания прекращается после двух циклов и отключено при prefers-reduced-motion.

Калькулятор оценивает условный эквивалент рабочего времени, а не результаты пилота.
Презентации: clients.html и vision-lab.html. PDF: clients.pdf и vision-lab.pdf.

Основной домен перенесён с yafufig/arospro-site. Поддомены pitch и lab обслуживаются отдельными репозиториями. Старые визуальные файлы не подключены к странице.
